# IT265 Module 2: One-Page Treatment

**Working game title:** Cat Cafe Chaos

In **Cat Cafe Chaos**, the player works at a small cat café and is responsible for keeping both customers and cats happy. Customers come into the café expecting drinks and clean tables, while the cats have their own needs and can create unexpected problems. The main challenge is that several people and cats may need attention at the same time, so the player must decide what problem to handle first.

The game should feel busy, playful, and slightly chaotic without becoming overwhelming. The player repeatedly checks the café, notices which customers or cats need attention, and decides which task is the most important. Tasks can include serving drinks, cleaning tables, feeding cats, finding missing toys, and petting unhappy cats. Completing a task changes the state of the café by improving a customer's patience or a cat's happiness, while ignoring a request for too long can make the situation worse. This creates a repeated cycle of noticing problems, prioritizing them, completing a task, and responding to whatever needs attention next.

The player's goal is to successfully manage the café during a short service period while keeping enough customers and cats happy. The main pressure comes from limited time and competing requests. The player cannot immediately complete every task, so choosing one task means temporarily leaving another task unattended. As the service period continues, new requests can appear and existing requests can become more urgent. The session ends when the service period is completed successfully or when too many customers and cats become unhappy.

The first version will focus on the prioritization mechanic rather than trying to create a complete café simulation. A physical prototype can use a simple café layout, customer and cat request cards, task cards, happiness or patience values, and a short timer or turn system. This will allow the core decision to be tested with inexpensive materials before adding more complicated features. Advanced cat behavior, café upgrades, decorations, and a larger menu can be added later if the central gameplay loop works. The distinctive part of the concept is the combination of normal café responsibilities with unpredictable cat-related problems, creating a playful time-management challenge.
